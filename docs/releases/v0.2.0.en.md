# v0.2.0 - Personal website workspace

[简体中文](v0.2.0.zh-CN.md) | **English**

Blog Studio evolves from a Fuwari-specific blog editor into the foundation of a personal website workspace for non-technical users. Fuwari remains the only fully supported base in this release, while the client core now reads projects through Blog Studio Standard 1.0 and a controlled base adapter.

## Create and manage sites

- New users start with Create a new site or Import an existing site.
- Creation selects the supported Fuwari style, collects basic site details, then creates and opens a real preview automatically.
- Import shows recognition, missing files, and automatic adaptation support before changing the project. Arbitrary Astro projects are not presented as supported.
- The overview gathers content, local history, publishing locations, and common actions.
- Primary navigation is now Overview, Content, Appearance, Publish, History, Site management, and Software settings.

## Blog Studio Standard 1.0

- A root `blog-studio.json` describes the base version, framework, theme, content and asset paths, page sections, controlled preview and build capabilities, and output directory.
- Descriptors select allowlisted capability IDs and cannot execute arbitrary system commands. Every mapped path must remain inside the site directory.
- Newly created Fuwari sites include the descriptor.
- Opening a v0.1.3 site creates a recovery point before adding the descriptor, without moving or rewriting the existing structure.

## Preserved capabilities

- Fuwari posts, drafts, pages, images, appearance settings, autosave, and real preview remain available.
- Multiple sites, timestamped source snapshots, copy-based history recovery, multiple private servers, GitHub Pages, and multi-target publishing remain available.
- Existing encrypted credentials stay associated with the unchanged absolute project path.
- Everyday screens use plain language; protocol details and build logs are placed inside advanced or technical disclosures.
- Only post editing and appearance use a split editor and live preview. Other primary pages use a focused single-column workspace.

## Scope

v0.2.0 does not support additional frameworks, arbitrary theme management, AI source generation, cloud hosting, or user accounts. The Windows package remains unsigned.

Package: `Blog-Studio-v0.2.0-Windows-x64.zip`.
