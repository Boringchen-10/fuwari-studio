# v0.1.2 · Blog Studio workspace settings

[简体中文](v0.1.2.zh-CN.md) | **English**

- Renamed the desktop product from Fuwari Studio to **Blog Studio** across the window, menus, and management UI.
- Added a Fuwari-style hue slider, light/dark/system theme, autosave delay, default preview device, and local cache directory.
- Accent colors and themes apply immediately; system mode responds to operating-system theme changes.
- The cache directory can be selected with a native folder picker and saved immediately.
- Improved settings cards, swatches, and mode selector; GitHub Pages and SFTP/SSH profiles are independent, with publish checkboxes for either target or both.

Package: `Blog-Studio-v0.1.2-Windows-x64.zip`. This release changes the local workspace only and does not alter published blog content. Back up the project before upgrading.
