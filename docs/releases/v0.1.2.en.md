# v0.1.2 · Blog Studio workspace settings

[简体中文](v0.1.2.zh-CN.md) | **English**

- Renamed the desktop product from Fuwari Studio to **Blog Studio** across the window, menus, and management UI.
- Added Workspace Settings for accent color, light/dark/system theme, autosave delay, default preview device, and local cache directory.
- Settings are stored locally; cache relocation takes effect after restart so active preview processes are not moved underneath the app.
- Reworked the workspace theme using Fuwari's OKLCH palette model: the selected hue now affects backgrounds, panels, inputs, borders, text, hover states, and selections across the whole interface, not only buttons.
- GitHub Pages and SFTP/SSH profiles are independent, and the publish center can target either one or both destinations.

This release changes the local workspace only and does not alter published blog content. Back up the project before upgrading.
