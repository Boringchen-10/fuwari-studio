# v0.1.1 · GitHub Pages Publishing

[简体中文](v0.1.1.zh-CN.md) | **English** | [Full v0.1 Overview](v0.1.0.en.md)

## Added

- Switch between SFTP/SSH and GitHub Pages in connection settings.
- Configure, test, and encrypt access tokens for public `username.github.io` homepage repositories.
- Upload built output to `fuwari-pages`, preserve Git history, and attempt to enable Pages and trigger deployment.
- Check deployment status against the current publish commit.
- GitHub setup documentation, upload size and file-count limits, and remote branch conflict checks.

## Changes and Corrections

- Distinguish uploaded output awaiting deployment from a live site; a successful commit is not reported as a successful deployment.
- Omit tokens from connection responses. A blank token preserves the saved token only for the same repository; switching repositories cannot reuse it.
- Use a versioned `0.1.1` local runtime directory to load the matching management interface.

These changes support the new GitHub workflow. No separate v0.1 SFTP or preview defect is claimed as fixed in this release.

## Known Issues and Scope

- GitHub can return 403 while enabling or triggering Pages after files have been committed. Check Settings → Pages for `Deploy from a branch`, `fuwari-pages`, and `/(root)`, then inspect Actions. Current error text does not distinguish the two Pages operations.
- Astro cache write conflicts with concurrent preview instances remain unresolved.
- Public GitHub.com homepage repositories only. No project subpaths, custom domains, private repositories, or Enterprise support.
- GitHub history contains static output, not Markdown source or drafts.
- The application UI remains Chinese; bilingual support here refers to project documentation.

## Upgrade

Back up your project, exit the old application, extract this version into a new folder, and use Project → Open Existing Blog to select your project. You may need to re-enter connection credentials in the new version. Keep the old data directory until migration is verified. The application is still unsigned.
