# v0.1.3 · Multiple sites and version timeline

[简体中文](v0.1.3.zh-CN.md) | **English**

- Added a Sites & Versions view for the active site, recently opened sites, and direct switching.
- Every build now creates an output directory labeled with its timestamp and site name, plus an editable source snapshot.
- The version timeline records creation time, site name, public URL, and publish targets. A snapshot can be restored as a separate project copy without overwriting the active site.
- Existing output-only release directories appear as legacy entries and are clearly marked as non-editable; static HTML is never presented as recoverable Markdown source.
- SFTP/SSH now supports multiple named profiles such as a primary host and a backup host, each stored and tested independently.
- The publish center exposes a separate checkbox for every SFTP profile and GitHub Pages, allowing one or several destinations.
- Fixed upgrades opening a fresh default project whose preview did not match the live site. The first launch imports older site paths, workspace settings, and encrypted connections.
- Workspace data now lives under stable `%APPDATA%\Blog Studio` storage, so upgrading or moving the application folder does not require reconnecting servers.

Package: `Blog-Studio-v0.1.3-Windows-x64.zip`.
