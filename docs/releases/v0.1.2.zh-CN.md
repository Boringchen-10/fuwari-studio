# v0.1.2 · Blog Studio 工作台设置

**简体中文** | [English](v0.1.2.en.md)

- 软件品牌由 Fuwari Studio 更名为 **Blog Studio**，窗口标题、菜单和管理端同步更新。
- 新增「工作台设置」入口：主题色、浅色/深色/跟随系统、自动保存延迟、默认预览设备和本地缓存目录。
- 设置保存到本机配置；缓存目录在重启后生效，避免运行中的预览进程被强制搬迁。
- 按照 Fuwari 的 OKLCH 色彩机制重做工作台主题：主题色会联动背景、面板、输入框、边框、文字、悬停和选中状态，而不只是按钮。
- GitHub Pages 与 SFTP/SSH 配置独立保存，发布中心可以单独选择任一目标，也可以同时发布到两个目标。

本版本只调整本地工作台，不修改已发布博客内容；升级前请备份项目。
