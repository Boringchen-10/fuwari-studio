# v0.1.2 · Blog Studio 工作台设置

**简体中文** | [English](v0.1.2.en.md)

- 软件品牌由 Fuwari Studio 更名为 **Blog Studio**，窗口标题、菜单和管理端同步更新。
- 新增「工作台设置」：Fuwari 风格主题色滑条、浅色/深色/跟随系统、自动保存延迟、默认预览设备和本地缓存目录。
- 主题色和明暗模式实时应用，跟随系统模式会响应系统主题变化。
- 缓存目录支持通过原生文件夹选择器选择并立即保存。
- 优化设置卡片、色板和明暗模式选择器，保留 GitHub Pages 与 SFTP/SSH 发布能力。

安装包：`Blog-Studio-v0.1.2-Windows-x64.zip`。本版本只调整本地工作台，不修改已发布博客内容；升级前请备份项目。
