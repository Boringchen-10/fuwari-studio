# v0.2.0 · 个人网站工作台

**简体中文** | [English](v0.2.0.en.md)

Blog Studio 从 Fuwari 专用博客编辑器升级为面向普通用户的个人网站工作台基础版本。当前仍只完整支持 Fuwari，但客户端核心通过 Blog Studio Standard 1.0 与基座适配层读取项目。

## 创建和管理网站

- 新用户首屏提供“创建新网站”和“导入已有网站”。
- 创建流程依次选择 Fuwari 样式、填写网站名称与个人资料，然后自动创建并打开真实预览。
- 导入前显示识别结果、缺失内容和能否自动适配，不把任意 Astro 项目标记为已支持。
- 网站概览集中显示文章、历史版本、发布位置与常用操作。
- 一级页面调整为网站概览、内容、外观、发布、历史版本、网站管理和软件设置。

## Blog Studio Standard 1.0

- 网站根目录新增 `blog-studio.json`，描述基座版本、框架、主题、内容和资源路径、页面区块、预览与构建能力以及输出目录。
- 描述文件只允许受控能力 ID，不执行任意系统命令；所有路径都限制在网站目录内。
- 新建 Fuwari 网站自动包含标准描述文件。
- 打开 v0.1.3 旧网站时先创建恢复点，再补充描述文件，不移动或重写原有结构。

## 保留的能力

- Fuwari 文章、草稿、独立页面、图片、外观设置、自动保存和真实预览继续可用。
- 多网站、带时间的源码快照、历史副本恢复、多台自有服务器和 GitHub Pages 多目标发布继续可用。
- 原网站绝对路径不变，因此现有加密连接资料继续按原网站关联。
- 日常界面使用普通用户文案，连接协议和构建日志收进高级或技术详情。
- 只有文章编辑与外观设置使用编辑区和实时预览双栏，其余页面使用清晰的单栏工作区。

## 支持范围

v0.2.0 不支持其他网站框架、任意开源主题自动管理、AI 生成源码、云端托管或账号系统。安装包仍未进行商业代码签名。

安装包：`Blog-Studio-v0.2.0-Windows-x64.zip`。
