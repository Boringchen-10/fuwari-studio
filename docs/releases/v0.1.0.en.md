# v0.1.0 · Initial Public Release

[简体中文](v0.1.0.zh-CN.md) | **English**

Fuwari Studio combines Fuwari post editing, appearance settings, live preview, and SFTP publishing in a local Windows application.

- Write posts, save drafts, set categories, tags, and covers; restore deleted posts from the recycle bin.
- Edit your avatar, bio, banner, theme color, navigation, About page, and friend links.
- Autosave and preview the real blog using desktop or mobile viewport sizes.
- Create blogs or open compatible projects without manually configuring Node.
- Build static websites and publish to your SFTP/SSH server using a password or private key.
- Confirm SSH fingerprints, encrypt credentials locally, back up replaced remote files, and attempt recovery on failure.

Supports Windows 10/11 x64. Extract the entire archive and run `Fuwari Studio.exe`; first launch prepares the environment. This version does not include GitHub Pages publishing.

Back up local projects separately. Static output is not a Markdown source backup. Multiple instances may cause preview cache conflicts. There is no one-click history restoration, automatic updater, or English UI yet. See the [README](../../README.en.md) for full details.
