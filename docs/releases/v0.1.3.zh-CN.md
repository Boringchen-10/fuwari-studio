# v0.1.3 · 多网站与版本时间线

**简体中文** | [English](v0.1.3.en.md)

- 新增「网站与版本」页面，可查看当前网站、最近打开的网站并直接切换。
- 每次构建都会生成以时间和网站名称标记的发布目录，同时保存可编辑源码快照。
- 版本时间线记录生成时间、网站名称、正式网址和发布目标；可从快照创建独立项目副本继续修改，不覆盖当前网站。
- 旧版发布目录会自动出现在时间线中，并明确标记为「仅发布文件」；静态 HTML 不会被错误地当作 Markdown 源码恢复。
- SFTP/SSH 支持多个命名配置，例如「阿里云主站」「备用服务器」，各配置独立保存和测试。
- 发布中心为每台 SFTP 服务器及 GitHub Pages 提供独立复选框，可单选或多选发布。
- 修复升级后打开新默认项目造成实时预览与线上网站不一致的问题；首次启动会自动导入旧网站路径、工作台设置及加密连接资料。
- 工作台数据改为保存在稳定的 `%APPDATA%\Blog Studio`，升级或更换程序文件夹后无需重新连接服务器。

安装包：`Blog-Studio-v0.1.3-Windows-x64.zip`。
