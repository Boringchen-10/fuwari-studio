# v0.1.0 · 首个公开版本

**简体中文** | [English](v0.1.0.en.md)

Fuwari Studio 将 Fuwari 博客的文章编辑、外观设置、实时预览和 SFTP 发布整合到一个 Windows 本地程序。

- 写文章、保存草稿、设置分类标签和封面，删除文章可从回收站恢复。
- 修改头像、简介、横幅、主题色、导航、关于页及友情链接。
- 自动保存并预览实际博客页面，可切换桌面和手机预览尺寸。
- 新建博客或打开兼容项目，无需手动配置 Node 环境。
- 构建静态网站，通过密码或私钥连接自有 SFTP/SSH 服务器发布。
- 确认 SSH 指纹、本机加密保存凭据，远程备份被替换文件并在失败时尝试恢复。

支持 Windows 10/11 x64。完整解压安装包后运行 `Fuwari Studio.exe`；首次启动需准备环境。此版本不包含 GitHub Pages 发布。

本地项目需要自行备份。发布输出不等于 Markdown 源码备份。多个实例可能造成预览缓存冲突；暂无一键历史恢复、自动更新或英文界面。完整使用说明见 [README](../../README.md)。
